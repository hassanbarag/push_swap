# Descripción:
## Este proyecto consiste en la creación de una libreria propia, la cual contiene una serie
## de funciones que recrean el comportamiento de funciones ya existentes, hechas por y para el alumno.
## Con ello se consigue que la persona entienda cómo la lógica, cómo funcionan y cómo usarlas. Según tengo entendido, esta librería la podre-
## mos utilizar en futuros proyectos dónde librerias estandard no sean permitidas.
##
# Instrucciones:
## Por un lado, tenemos las funciones, archivos ".c" dónde el alumno ha plasmado el código; por otro lado tenemos la librería
## propiamente dicha, la qual contiende todos los prototipos de las funciones, antes ya mencionadas. Para compilar, tenemos 
## un archivo "Make", cuya función es automatizar el "montaje" del programa. Se llama desde la terminal y este crea la libreria estatica.
## Para usarla simplemente necesitamos llamar a la libreria con un include para poder usar las funciones.
